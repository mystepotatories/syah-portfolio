# Design — Syahirah Portfolio

A locked design system for a kinetic, image-led working archive. Project interface captures are the visual identity; chrome stays quiet so the work remains dominant.

## Genre

Atmospheric, kinetic and confidently work-led.

## Macrostructure family

- Portfolio pages: Photographic, with a full-bleed featured image followed by vertical project folds.
- Navigation: N9 edge-aligned minimal.
- Footer: Ft1 mast-headed.
- Project detail: Immersive overlay that preserves the full, uncropped source image.

## Theme

Warm near-black, warm white type and one acid-amber action colour. Project screenshots retain their original colours; dark scrims provide consistent text contrast.

## Typography

- Display: Bricolage Grotesque, weight 600–800.
- Body: IBM Plex Sans, weight 400–600.
- Display tracking: -0.07em to -0.09em for large headlines.

## Spacing

4-point named scale defined in `tokens.css`. Layouts use fluid gutters and content-driven `40rem` / `60rem` breakpoints.

## Motion

- Transform and opacity only.
- Featured images crossfade and settle from a restrained crop scale.
- Project images respond to fine-pointer hover; a continuous skills marquee pauses on interaction.
- Reduced motion removes spatial movement and stops the marquee.

## Microinteractions stance

- Every hover response has a focus or direct-touch equivalent.
- Buttons provide immediate press feedback and visible focus rings.
- Escape and explicit close controls dismiss project overlays.
- Motion guides image selection and project opening; it does not decorate body text.

## CTA voice

- Short, verb-led labels: “View project”, “Open case”, “Back to projects”.
- Acid amber is reserved for focus, active selection and decisive actions.

## What pages must share

- NS+ wordmark, acid-amber accent and display/body pairing.
- Edge-aligned navigation, full-bleed image rhythm and honest project information.
- No invented outcome metrics or fake client claims.

## Per-page allowances

- Image positioning may vary per screenshot to protect essential interface content.
- Portrait work can use a contained presentation inside the same photographic fold.
- New project captures may be added without changing the macrostructure.
